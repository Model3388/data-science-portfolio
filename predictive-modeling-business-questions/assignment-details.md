# Framing Predictive Questions for Business Applications

## Overview

Predictive modeling begins with asking the right questions. This project explores how to formulate predictive questions that align with business objectives and can be addressed using data-driven methods.

## Fast-Food Franchise Use Case

As a manager of a fast-food franchise, predictive modeling can help improve operational and financial performance.

### Predictive Questions

1. Would targeted television advertising to teenagers increase sales and profits?
2. Would implementing Geographic Information Systems (GIS) improve customer traffic?
3. Would increasing staffing levels improve customer satisfaction?

Each question identifies:

* An independent variable (e.g., advertising, staffing)
* A dependent variable (e.g., sales, customer satisfaction)

## Technology Industry Use Case

Applying predictive modeling to the technology sector:

### Predictive Questions

1. Would influencer partnerships increase video engagement?
2. Would monetizing user interactions increase platform activity?

## Key Considerations

* Predictive questions must be measurable
* Variables should be clearly defined
* Outcomes should align with business goals

## Conclusion

This project demonstrates that effective predictive modeling begins with strong problem formulation. Well-defined questions enable organizations to build models that generate actionable insights and drive business value.
