# Demand Forecasting Using Time Series Analysis

## Overview

This project explores how historical demand data can be used to forecast future values using time series analysis.

## Scenario

A company tracks demand for a product over time and wants to estimate future demand based on past observations.

## Methodology

* Historical demand data was plotted to visualize trends
* Patterns in growth were analyzed
* A simple forecasting approach was used to estimate future demand

## Observations

* Demand shows a steady upward trend
* Recent increases suggest continued growth
* No strong seasonal variation is evident in the dataset

## Forecast

Based on the trend, future demand is expected to increase. A projection was made using recent data trends to estimate the next period’s demand.

## Limitations

* Small dataset limits reliability
* No external variables included (e.g., economic factors, promotions)
* Model assumes continuity of past trends

## Conclusion

This project demonstrates how time series analysis can be used to generate simple but useful forecasts. While basic, this approach provides a foundation for more advanced forecasting models.
